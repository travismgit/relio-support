Relio Markdown Viewer

A read-only Markdown reader for macOS. Support and documentation.

Contact

Questions, bug reports and feature requests: relio_support@icloud.com

It helps to include your macOS version and, if a specific document renders wrongly, the document itself or a small excerpt that reproduces it.

Requirements

macOS 13 or later. Relio is a universal app and runs natively on both Apple silicon and Intel Macs.

Opening documents

Relio opens Markdown files — .md, .markdown, .mdown, .mkd, .mdtext and .qmd. Use File → Open, double-click a file in Finder, or drag one onto the app icon.

There is no account and no sign-in. Relio cannot modify your documents: it has no save command and no code that writes to the file you are reading, and macOS labels its windows Locked to reflect that.

Making Relio the default for Markdown

Relio offers itself as an alternate handler so it never takes .md away from your editor. To make it the default: right-click any Markdown file in Finder → Get Info → Open with → Relio → Change All…

Finder previews (Quick Look)

Select a Markdown file in Finder and press the space bar. Relio renders the document rather than showing raw text.

If the preview looks like plain text: macOS picks the preview provider belonging to the file type's default handler, so Relio's preview only appears once Markdown is bound to Relio. Use the Get Info → Open With → Change All… steps above, then press space again. If another Markdown preview app is installed, turn it off in System Settings → General → Login Items & Extensions → Quick Look.

Exporting

File → Export → PDF… or HTML… asks where to save. The PDF is one continuous page rendered from the document; for paper pages use ⌘P and Save as PDF from the print dialog, which applies the print stylesheet. Exported HTML is a single self-contained file with your theme included and no external assets.

What Relio renders

GitHub-Flavored Markdown, tables with numeric columns aligned automatically, Mermaid diagrams, syntax highlighting across 36 languages, footnotes, task lists, and YAML frontmatter stripped rather than printed. Everything runs on your Mac; Relio makes no network requests.
