Privacy Policy

Relio Markdown Viewer — last updated 22 October 2026

Relio collects no data

Relio does not collect, transmit, store or share any personal information. There is no account, no sign-in, no analytics, no telemetry, no crash reporting and no update check.

It makes no network connections

Relio works entirely offline. Every library it uses — the Markdown parser, the diagram renderer, the syntax highlighter — is compiled into the application itself and runs on your Mac.

The app does request the com.apple.security.network.client entitlement. This is a technical requirement of the system component Relio uses to draw documents (WKWebView), which fails to launch without it. Relio itself contacts no servers, and the documents you open are never uploaded anywhere.

Your documents stay yours, and stay unchanged

Relio is a reader. It opens Markdown files read-only and has no code path that writes to them — macOS marks its windows “Locked” to reflect this.

Files are only ever read when you open them, or when you preview them in Finder. Nothing is indexed, copied or retained after you close the window.

The one exception is export, which you have to ask for: choosing Export opens a save panel and writes a PDF or HTML copy to the location you choose, and nowhere else.

What is stored on your Mac

Your chosen theme, appearance and text size are saved in the app's own preferences on your Mac. They never leave it.
